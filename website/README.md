# Modern Starter Website

A fast, responsive, and accessible static site starter (HTML/CSS/JS).

## Getting started

- Open `website/index.html` directly in your browser, or
- Serve the folder locally:

```bash
# using Python
python3 -m http.server --directory /workspace/website 5173
# then visit http://localhost:5173/index.html
```

## Structure

- `index.html` – main page markup
- `styles.css` – global styles and layout
- `script.js` – interactivity (nav, smooth scroll, contact form)

## Customize

- Replace the hero image URL in `index.html` with your own
- Edit colors/spacing in `styles.css`
- Wire the form to your backend or a service like Formspree
